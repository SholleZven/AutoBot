# AutoBot

Telegram бот для отслеживания технического обслуживания автомобилей.

## Возможности

- 🚗 Добавление и управление автомобилями
- 📋 Создание задач обслуживания с интервалами по пробегу
- 📊 Отслеживание пробега и уведомления о необходимости обслуживания
- 🤖 Удобный интерфейс через Telegram

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   composer install
   ```

3. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```

4. Сгенерируйте ключ приложения:
   ```bash
   php artisan key:generate
   ```

5. Настройте базу данных в `.env`:
   ```
   DB_CONNECTION=...s
   DB_DATABASE=...
   ```

6. Создайте базу данных:
   php artisan migrate
   ```

7. Получите токен бота у [@BotFather] и добавьте в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   ```

## Запуск

### Обычный режим (в терминале)
```bash
php artisan bot:start
```

### Фоновый режим (daemon)
```bash
php artisan bot:start --daemon
```

### Остановка бота
```bash
php artisan bot:stop
```

### Проверка статуса
```bash
php artisan bot:status
```

## Команды бота

- `/start` - начать работу с ботом
- `/addcar <название> <пробег>` - добавить автомобиль
- `/mycars` - показать мои автомобили
- `/addtask <ID авто> <описание> <интервал>` - добавить задачу обслуживания
- `/mytasks` - показать мои задачи
- `/mileage <ID авто> <пробег>` - обновить пробег
- `/help` - справка по командам

## Примеры использования

1. Добавить автомобиль:
   ```
   /addcar Toyota Camry 120000
   ```

2. Добавить задачу обслуживания:
   ```
   /addtask 1 Замена масла 5000
   ```

3. Обновить пробег:
   ```
   /mileage 1 125000
   ```

## Дополнительные команды

- `php artisan bot:ask-mileage` - запросить пробег у всех пользователей
- `php artisan bot:polling` - запустить polling напрямую

## Требования

- PHP 8.1+
- Laravel 10+
- SQLite (или другая поддерживаемая БД)
- Telegram Bot Token
